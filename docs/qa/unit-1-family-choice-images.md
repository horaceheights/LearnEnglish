# Unit 1.5 family-group images

These two images were generated with the built-in image-generation tool using the established cast as references. They remain pending human review in the Preview app; this record is not a Production approval.

Canonical assets:

- `Lessons/Lesson1/images/family_grandparents_grandchildren.webp`
- `Lessons/Lesson1/images/family_parents_children.webp`

Each asset is mirrored byte-for-byte in the frontend and mobile lesson-asset directories. Both are 1536 × 1024 (3:2). The first depicts only the two grandparents and five grandchildren; the second depicts only the two parents and five children. No generation is mixed into the other group. The authored contrast tests the stated family members, not whether only one of the groups is a family.
