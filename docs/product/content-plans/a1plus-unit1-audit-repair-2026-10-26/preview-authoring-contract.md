# Local Unit 1 content preview

This package is a local candidate for the user's content review, not installed content or publication. Preserve the approved v9 lesson order, language boundaries, precise arrive wording, and existing image files. Read source/unit-1-plan-v9.json and image-manifest-v2.json plus the relevant project guardrails/new-content-engine. Use only existing images; record any real image gap instead of substituting an irrelevant photograph.

Each author writes one JSON array of lessons to preview-lessons-N-N.json in this directory. Do not modify other authors' files. No HTML or audio generation by content authors.

Lesson: {id, title, outcome, kind: teaching|review|mission, vocabulary:[], cards:[]}. Vocabulary contains exact newly taught English words/chunks for emphasis, not planning descriptions; review and mission may have an empty list.

Card: {id, stage, activity, context_es, instruction_es, turns:[], ...}
- id: stable lesson-prefixed string, e.g. 1.1-L01.
- stage: Learn, Recognize, Listen, Speak, Use, or Mission. Standard and review lessons follow the five stages. Mission stays one authored continuous sequence.
- activity: teach, choice, speak, build, end.
- turns: exact ordered spoken lines [{speaker,text,image?,translation_es?,clock?}]. speaker: ana, luis, teacher, co-teacher, sofia, diego. Use teacher/co-teacher for offscreen narration. image is an existing manifest ID. clock is {hour:1..12,minute:0..59}; only when this single line states one exact time. Timed frames are unsupported: use one reviewed illustration per complete spoken turn, separate complete turns, or an independently readable static teaching record. A single Use model may omit its illustration and compile to the existing scalar-audio surface; never invent visual evidence. Removing animation does not approve an ambiguous action photograph.
- context_es: concise, non-answer-revealing Spanish scene setup. instruction_es: concise task instruction.
- teach: include accurate translation_es on each turn; each card introduces a declared target or its adjacent contextual reply. No arbitrary new vocabulary or known-word-only filler.
- choice: prompt (visible English only where appropriate); image (optional neutral main photo or actual Recognize prompt image); options:[{id,text?,image?,clock?}]; answer: semantic option ID; feedbackByOption:{wrongOptionId:explanation_es} as review expectations. IDs describe the actual meaning, including person/time/record pattern where assessed; A/B labels and filename lookups are not semantics. The shared application resolver supplies live feedback. answerTurns is an optional exact reply after correct; do not repeat a single unchanged Listen prompt as its answer. Correct answer must be unambiguous; all options same kind. For image-to-text Recognize, turns=[] and answerTurns contains the correct sentence. For text-to-image Recognize, prompt equals the complete spoken prompt, and spanish_translation contains its complete accurate Spanish translation. Listen/Mission hides transcript and assessed clock until answered. Never show the answer image before listening. Ordinary Listen uses taught English evidence and the shared generic instruction; neutral context cannot name the missing question category or reveal the answer. Preserve supported inference/reformulation outcomes. No assessment based on inferred reasons, routines, willingness, or times from a photo.
- speak: exact model turns then learner recording. No synthetic pronunciation grade. Standard content preview uses real local microphone/playback, with honest grading boundary.
- build: target is exact sentence, spanish_translation is its complete Spanish meaning, turns=[same full spoken target]. guided:[two zero-based token positions] for the first floor(N/2) Use cards, with at least one fixed word; omit guided in the second half for full sentence assembly. Split tokens on spaces, preserving punctuation. 2–8 words per full target. Exact tile words only, no distractors. Preserve adjacent dialogue despite question length. Use known concise replies when longer source models exceed 8 words.
- mission: source choices use mission_kind:conversation-decision and compile to the reusable mission_game kind with an ordinary answer bank and no invented hotspot geometry. Authored lesson.mission supplies the canonical presentation (kickoff_image is a manifest ID); chapters have id/title/objective. The accepted physical outcome is completionScene:{image,context_es} on the final decision, before four consecutive closing speaks marked mission_kind:voice-gate. Each closing gate has a question turn plus a distinct written-only speakTarget response image/text. Do not synthesize learner-answer audio or add an extra end card after the gates.

All content must be fully authored, including correct/distractor choices and exact spoken replies. Do not just repeat source models in all stages. Respect two-choice initial practice and meaningful later growth to three choices in ordinary cards; wide images remain 3:2. Two image choices stack at full card width. Some targets legitimately continue in subsequent lessons; do not pad counts. Reuse existing exact speaker/text/delivery clips where available; root generates missing takes using the established voice profiles. Preserve unchanged occurrence-bound pronunciation takes only when sentence, speaker, source hash and prepared hash all match. Changed occurrences remain explicitly pending preparation/verification. No browser speech synthesis.

Ensure every intended lesson function has successful-path evidence, a real fresh check, explicit day/period context and factual availability for meetings. Start/finish are distinct. Teach wake/get up and put on/take off with complete English models and reviewed single-action scenes; a silent assessment may not ask the learner to infer opposite motion from an ambiguous pose. Frequency requires readable scoped records, not guesses from people studying. Review uses the prepared Sofia/Diego fresh images with correct speaker identity. Mission resolves the accepted library visit and includes varied conversation decisions and meaningful speaking acts in one continuous sequence. New or changed media require semantic, crop and human review; file existence or generation is not approval.
